# risk-review-skill

> 风控审核技能包，供 risk-officer agent 使用。

## 审核标准

### 选股筛选审核
- 筛选条件是否覆盖用户要求
- 候选标的数量是否合理（3-10只为宜）
- 每只标的是否有明确的入选理由
- 是否存在明显的基本面缺陷未被提示

### 深度分析报告审核
- 基本面分析是否完整（业务、财务、估值三项齐全）
- 财务数据是否有逻辑错误（如 ROE 与净利率、杠杆的关系）
- 技术面分析与基本面结论是否自洽
- 目标价是否有合理依据，不能凭空给出
- 风险提示是否充分（至少3项具体风险）
- 是否包含免责声明

### 交易计划审核
- 止损位是否明确（不能是"跌破支撑就止损"这种模糊表述）
- 仓位建议是否合理（单只股票不超过总仓位的 20%）
- 止盈目标与分析报告目标价是否一致
- 分批建仓方案是否合理
- 是否包含持有周期说明
- 是否包含免责声明

### 策略回测审核
- 回测区间是否包含牛熊完整周期
- 绩效指标是否完整（收益、回撤、夏普、胜率均需列出）
- 是否与基准指数进行了对比
- 最大回撤是否在可接受范围内（通常 <30%）
- 是否明确标注回测局限性
- 是否包含免责声明

---

## 输出规范

### PASS 格式
```
PASS

通过原因：[简要说明，1-2句，点明核心质量亮点]
```

### FAIL 格式
```
FAIL

问题1：[具体位置] — [问题描述] — [修改方向]
问题2：[具体位置] — [问题描述] — [修改方向]
...
```

---

## 审核原则

- 只评判内容质量和风险合规性，不重写内容
- 问题定位要具体（精确到某个指标或某段描述）
- FAIL 时必须给出可操作的修改方向
- 对于学习研究性内容，重点审核逻辑自洽性和免责声明完整性
- 所有产出必须包含"仅供学习研究，不构成投资建议"的声明，否则直接 FAIL
