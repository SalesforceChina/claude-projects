# stock-analysis-skill

> 股票分析技能包，供 analyst agent 使用。

## 选股筛选规范

根据用户指定条件从 A 股 / 港股 / 美股中筛选候选标的。

### 常用筛选维度
- 市值区间（如市值 > 100 亿）
- 盈利能力（ROE、净利润增速、毛利率）
- 估值水平（PE、PB、PS）
- 行业赛道（消费、科技、医药、新能源等）
- 技术形态（均线系统、成交量、突破形态）

### 输出格式
```
## 选股结果 — [日期]

**筛选条件**：[复述用户条件]

| 代码 | 名称 | 市值 | PE | ROE | 筛选理由 |
|------|------|------|----|-----|--------|
| ...  | ...  | ...  | .. | ... | ...    |

**备注**：数据基于公开市场信息，仅供参考。
⚠️ 以上内容仅供学习研究，不构成投资建议
```

## 深度分析规范

### 基本面分析
- **业务概况**：主营业务、市场地位、护城河
- **财务分析**：营收增速、净利率、ROE、负债率、现金流
- **估值分析**：PE/PB/PS 横纵向对比，DCF 估算（如适用）

### 技术面分析
- **趋势判断**：均线系统（5/10/20/60日）、趋势方向
- **关键位置**：支撑位、阻力位、近期高低点
- **指标参考**：MACD、RSI、成交量变化

### 综合评级
- 评级：强烈推荐 / 推荐 / 中性 / 回避
- 目标价区间（6-12个月）
- 主要风险提示

### 输出格式
```
## [股票代码] [股票名称] 深度分析报告

**分析日期**：YYYY-MM-DD
**当前价格**：XX 元
**目标价区间**：XX - XX 元
**综合评级**：[评级]

### 一、基本面分析
...

### 二、技术面分析
...

### 三、估值分析
...

### 四、风险提示
...

## 策略回测规范

### 回测要素
- **策略名称**：简洁描述策略核心逻辑
- **回测区间**：建议 1-3 年历史数据
- **入场条件**：明确的量化触发规则
- **出场条件**：止盈、止损、时间止损
- **仓位管理**：每次建仓比例

### 绩效指标
- 总收益率 vs 同期基准（沪深300/纳斯达克等）
- 年化收益率
- 最大回撤
- 夏普比率
- 胜率 & 盈亏比

### 输出格式
```
## [策略名称] 回测报告

**回测区间**：YYYY-MM-DD 至 YYYY-MM-DD
**标的池**：[描述]

- 仓位：...
