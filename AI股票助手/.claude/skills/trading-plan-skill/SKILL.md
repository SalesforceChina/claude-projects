# trading-plan-skill

> 交易计划技能包，供 trader agent 使用。

## 交易计划制定规范

基于分析报告，输出可执行的交易计划。

### 核心要素（必须包含）

1. **建仓条件**：具体的价格触发条件或技术信号
2. **仓位建议**：占总资金的比例（如 5%-10%）
3. **建仓方式**：一次性建仓 / 分批建仓（推荐分批）
4. **止损位**：明确价格，不能模糊表述
5. **止盈目标**：第一目标价、第二目标价
6. **持有周期**：预期持有时间范围

### 输出格式

```
## [股票代码] [股票名称] 交易计划

**制定日期**：YYYY-MM-DD
**参考分析**：research/[代码]-analysis.md

### 建仓策略
- **建仓条件**：价格回调至 XX 元附近 / 突破 XX 元
- **建仓方式**：分两批建仓
  - 第一批（50%仓位）：XX 元附近
  - 第二批（50%仓位）：XX 元附近
- **建议仓位**：占总资金的 X%

### 风控设置
- **止损位**：XX 元（亏损幅度约 X%）
- **止损逻辑**：[说明止损原因]

### 止盈目标
- **第一目标**：XX 元（收益约 X%）
  - 操作：减仓 50%，其余持有
- **第二目标**：XX 元（收益约 X%）
  - 操作：清仓

### 持有周期
- 预期持有：X 至 X 个月
- 定期复盘：每月末评估一次

### 注意事项
- [列出影响该交易计划的关键风险]

⚠️ 以上内容仅供学习研究，不构成投资建议
```
