# film-storyboard-skill

> 影视分镜技能包，供 storyboard-artist agent 使用。

## 节拍拆解（Beat Breakdown）

从剧本中识别叙事曲线的关键拐点，生成节拍拆解表。

### 输出格式

```
## Beat Breakdown — [集数标识]

| # | 节拍名称 | 情绪弧线 | 核心事件 | 视觉重点 |
|---|--------|--------|--------|--------|
| 1 | ...    | ...    | ...    | ...    |
```

## Beat Board 九宫格提示词

基于节拍拆解表，为每个关键节拍生成九宫格静态分镜提示词。

### 输出格式

```
## Beat Board — [节拍名称]

### 格1：[场景描述]
[提示词内容]

### 格2：...
```

## Sequence Board 四宫格提示词

将九宫格中的关键镜头进一步细化为连续动作序列。

### 输出格式

```
## Sequence Board — [场景名称]

### 镜头1：[描述]
[提示词内容]

### 镜头2：...
```

## 通用提示词规范

- 采用中文叙事描述式，不使用英文
- 包含：景别、机位、光线、色调、主体动作、情绪氛围
- 格式：[景别] + [主体] + [动作/状态] + [环境/光线] + [情绪氛围]
