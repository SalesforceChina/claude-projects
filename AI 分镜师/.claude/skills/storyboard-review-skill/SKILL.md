# storyboard-review-skill

> 分镜审核技能包，供 director agent 使用。

## 审核标准

### 节拍拆解审核
- 节拍数量是否合理（通常 7-12 个）
- 每个节拍是否有明确的叙事转折点
- 情绪弧线是否完整（起伏有序）
- 视觉重点是否具体可执行

### Beat Board 九宫格审核
- 九格是否覆盖节拍的完整叙事
- 每格提示词是否包含：景别、主体、动作、环境、情绪
- 镜头语言是否多样（不能全是同一景别）
- 提示词是否为中文叙事描述式

### Sequence Board 四宫格审核
- 四格是否构成连贯的动作序列
- 镜头切换逻辑是否流畅
- 是否体现了运动感和节奏变化

## 输出规范

### PASS 格式
```
PASS

通过原因：[简要说明，1-2句]
```

### FAIL 格式
```
FAIL

问题1：[位置] — [问题描述] — [修改方向]
问题2：...
```

## 审核原则

- 只评判内容质量，不重写内容
- 意见具体到格号或节拍编号
- FAIL 时必须给出可操作的修改方向
