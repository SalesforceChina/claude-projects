# animator-skill

> 动态提示词技能包，供 animator agent 使用。

## Motion Prompt 规范

将静态分镜的每一格转化为图生视频的动态提示词。

### 核心要素（必须包含）

1. **镜头运动**：推、拉、摇、移、跟、升、降、固定
2. **主体动作**：具体的身体动作或表情变化
3. **运动节奏**：缓慢/流畅/急促/爆发
4. **时长参考**：建议秒数（3-6秒为宜）

### 可选要素

- 景深变化（焦点转移）
- 光线变化（光影流动）
- 环境动态（风、烟、水等）

## 输出格式

```
## Motion Prompt — [集数] [节拍名称]

### [格号]：[场景简称]
**镜头运动**：[描述]
**主体动作**：[描述]
**节奏**：[缓慢/流畅/急促]
**时长**：约 X 秒

提示词：[完整中文动态描述]
```

## 提示词写法规范

- 用动词开头，描述运动过程
- 避免静态描述，强调"变化"和"过渡"
- 格式：[镜头运动方式] + [主体动作] + [环境变化] + [情绪节奏]
- 示例："镜头缓缓推近，人物抬起头，眼神从迷茫逐渐聚焦，背景灯光由暗转亮"
